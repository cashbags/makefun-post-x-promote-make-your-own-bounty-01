## The entry

- `main.ts` — copies `POST.json` to the output directory after checking it is a JSON object whose `url` is shaped like an X post address. Node stdlib only, no network, deterministic.
- `POST.json` — the address of the post. Currently the clearly-marked placeholder `https://x.com/<handle>/status/<id>`: the post goes up from Dame's own public X account, and the placeholder is replaced with its real address once he posts it.
- `LICENSE` — MIT.
